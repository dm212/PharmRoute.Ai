# 48-hour delivery plan

## Phase 1 - Foundation

- Confirm the scope and evaluation strategy.
- Scaffold frontend and backend applications.
- Document the architecture and initial graph model.
- Establish safe environment-variable conventions.

## Phase 2 - Graph layer

- Define constraints and indexes.
- Create realistic deterministic seed data.
- Implement batch lookup, provenance traversal, and indirect exposure queries.
- Confirm that all application queries are parameterized.

## Phase 3 - Spring Boot API

- Add configuration, controllers, services, and graph repositories.
- Validate user input and normalize API responses.
- Add clear unreachable-database and not-found behavior.

## Phase 4 - Investigation experience

- Build the batch search and overview.
- Build a readable supply-chain timeline.
- Build related-risk evidence cards and investigation paths.
- Add responsive, loading, empty, and error states.

## Phase 5 - Quality and automation

- Add backend unit/integration tests and frontend checks.
- Add CI for builds and tests.
- Review secret handling and deployment configuration.

## Phase 6 - Delivery assets

- Deploy the API and web application.
- Capture UI screenshots.
- Complete setup, query, and deployment documentation.
- Prepare and record a concise end-to-end walkthrough.

## Phase 7 - Submission audit

- Verify every assessment requirement against repository evidence.
- Test the hosted experience from a clean browser.
- Prepare the repository URL, demo URL, recording URL, and submission email.
